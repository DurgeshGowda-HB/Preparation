## Amazon Elastic Compute Cloud (Amazon EC2)

Amazon EC2 (Elastic Compute Cloud) is a service that provides **virtual servers** in the cloud to run applications.

<h3>Why Do We Need EC2?</h3>

Traditionally, running an application requires:

- Buying a Physical Server
- Installing an Operating System
- Maintaining Hardware
- Upgrading Resources

With EC2, AWS provides virtual servers on demand.

<h2>What is Amazon EC2?</h2>

> **Definition:** Amazon EC2 is a cloud computing service that provides resizable virtual servers (instances) to run applications.

Simply:

> **EC2 = Rent a Virtual Computer in the Cloud.**

<h3>How EC2 Works</h3>

```text
User
```

<h2>Key Components</h2>

### EC2 Instance

> A virtual machine running in AWS.

### AMI (Amazon Machine Image)

> A template used to launch an EC2 instance.

It contains:

- Operating System
- Software
- Configuration

### Instance Type

> Defines the CPU, RAM, Storage, and Network capacity of an EC2 instance.

Example:

- t2.micro
- t3.micro
- t3.small

### Key Pair

> Used to securely connect to an EC2 instance using SSH.

### Security Group

> A virtual firewall that controls inbound and outbound traffic.

### Elastic IP

> A static public IP address that can be associated with an EC2 instance.

<h3>Common Use Cases</h3>

- Web Hosting
- Running Backend Applications
- Hosting APIs
- Development & Testing
- Batch Processing
- Game Servers

<h3>Benefits of Amazon EC2</h3>

- On-demand Virtual Servers
- Easy to Scale
- Pay-as-you-go
- Secure
- Highly Available
- Multiple Operating Systems Supported

<h3>EC2 vs Physical Server</h3>

| Feature | Physical Server | Amazon EC2 |
|---------|-----------------|------------|
| Setup Time | Days or Weeks | Minutes |
| Initial Cost | High | No Upfront Cost |
| Scalability | Difficult | Easy |
| Maintenance | Self Managed | AWS Manages Hardware |
| Pricing | Buy Hardware | Pay-as-you-go |

<h2>Key Takeaways</h2>

- EC2 provides **virtual servers** in the cloud.
- An **EC2 Instance** is a virtual machine.
- **AMI** is used to launch EC2 instances.
- **Instance Type** determines CPU, RAM, and other resources.
- **Security Groups** protect EC2 instances.
- **Key Pairs** are used for secure login.
- **Elastic IP** provides a static public IP address.
- EC2 follows a **Pay-as-you-go** pricing model.
